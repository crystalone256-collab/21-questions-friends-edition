# 21 Questions — Friends Edition

A shareable 21-question friendship challenge built with Next.js and Supabase.

## Setup
1. Create a Supabase project.
2. Run `supabase-schema.sql` in Supabase SQL Editor.
3. Add `NEXT_PUBLIC_SUPABASE_URL` and `SUPABASE_SERVICE_ROLE_KEY` to your Vercel environment variables.
4. Deploy this repository on Vercel.

Keep the service role key private. Never use it as a `NEXT_PUBLIC_` variable.
